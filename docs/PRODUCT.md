# Product scope

MathModel AI accepts competition problems and attachments and ultimately builds
a reproducible submission package. Correctness and provenance outrank novelty.

The current release completes Phase 3. In addition to the Phase 2 reasoning
core, it safely registers and parses supported attachments, computes typed data
profiles, routes structured/multimodal data interpretation, tracks artifacts,
and records isolated Python execution. It does not claim that Mock-generated
analysis is mathematically correct, and it makes no mathematical-model, solver,
literature, or benchmark-completion claim. Those capabilities are outside the
current phase.
