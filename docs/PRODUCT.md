# Product scope

MathModel AI accepts competition problems and attachments and ultimately builds
a reproducible submission package. Correctness and provenance outrank novelty.

The current release completes Phase 2. It can structure a text problem,
separate evidence categories, decompose linked subproblems, explore candidate
models, and persist a deterministic primary/backup decision. It does not claim
that Mock-generated analysis is mathematically correct, and it makes no solver,
literature, attachment, or benchmark-completion claim. Those capabilities are
outside the current phase.
